# The Shaikh Academy — Premium React Site

## Run in VS Code
1. Extract this folder and open it in VS Code.
2. Open Terminal > New Terminal.
3. Run: `npm install`
4. Run: `npm run dev`
5. Ctrl+click the local URL shown by Vite (usually http://localhost:5173).

## Edit
- Coach content: `src/data/coaches.js`
- Main page: `src/App.jsx`
- Styling: `src/styles.css`
- Images: `public/assets/`

The contact email is a placeholder. Replace `hello@theshaikhacademy.com` before publishing.
